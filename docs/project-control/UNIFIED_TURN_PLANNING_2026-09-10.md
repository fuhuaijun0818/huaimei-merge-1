# 售前对话统一理解与任务推进改造

日期：2026-09-10。范围：本地售前聊天后端；本次没有部署线上环境。

## 当前流程

客户消息 → 会话与人工接管检查 → 医疗/隐私等强制边界 → 每轮模型计划 → 计划校验 → 联系方式保存和知识查询 → 自然语言生成/审核 → 持久化任务状态 → 前台回复与后台会话同步。

每个正常 A-01 异步对话轮次都先请求模型计划，不再依赖规则初判是否属于少数“可修正意图”。计划包括主意图、最多三个需要回答的问题、必要澄清、当前轮新增信息、预约意愿及下一步。原始消息保持不变，用于审计和强制边界；消解指代后的问题用于知识查询。同步规则调用仍用于离线测试和降级。

## 已实现

- 模型计划可替换错误的规则初判，不再受旧意图白名单约束。对项目、医生的关联仍检查其是否出现在客户消息或既有会话中。
- 多问题分别获取现有知识处理器的回答和证据，再组织为一条答复；不只回答主意图。
- 已验证的预算、时间、风格和关注点写入会话，并保留来源。新增值必须逐字出现于本轮消息；不合法的可选字段丢弃，不把历史日期当作新日期。非法整体结构、低置信度或不可信查询回退规则处理。
- 明确的拒绝和暂缓保持为 deferred；新意愿可恢复推进。改期覆盖旧的期望时间。预约计划只产生待客户确认的登记入口，不等于锁定接诊名额。
- 联系方式处理从提前返回分支移至统一理解之后。姓名与手机号在本地提取和格式校验，模型看到的是占位符。支持姓名在号码前后、明确姓名/电话标签、空格分段和 +86；多个号码、示例、明确他人号码等不自动归属客户。
- 留资成功以保存接口回执为准；失败明确说明未保存。混合消息先确认保存状态，再继续回答。已留资或暂缓预约后，隐藏重复留资提示。
- 强制安全与人工接管仍优先。模型无法凭输出直接执行任意业务接口；写操作只能通过服务端传入的内部回调。
- 不允许把偏好记忆说成“已为您登记”，不允许无回访任务的“稍后顾问会联系”等承诺。
- 单轮规划最多 8 秒、生成最多 10 秒且不重试、审核最多 6 秒，减少超过网关 30 秒时限的风险。外部查询和存储开销另计，不是整体 SLA 保证。
- 规划是否采用、失败原因、丢弃字段/步骤、耗时及规划 token 数可追踪。

## 验证证据

- `npm run test:turn-planning`：统一规划 36 项检查，加既有联系方式、语义追问、售前多轮回归。
- 现有运行时、会话、预约编排、自然回答、模型客户端、联系方式隐私边界检查通过；安全红队开发集 60/60 通过。
- 既有独立 HTTP 服务回归通过，包含渠道、幂等和人工接管。该套固定文案测试使用 `HUAMEI_NATURAL_DIALOGUE_ENABLED=false HUAMEI_SEMANTIC_UNDERSTANDING_ENABLED=false`，避免 `.env.local` 自然回答配置改变气泡数量断言；统一模型路径由新增测试和真实模型测试覆盖。
- `UNIFIED_TURN_PLANNING_LIVE_2026-09-10.json`：实际配置的 qwen3.7-flash，8 轮模拟客户对话，全部规划及行为检查通过；本轮约 1.6～5.5 秒。使用隔离存储，关闭院方会员查询。此前测试暴露的任务证据、旧日期提取和执行承诺问题已修正，报告保存最终结果。
- `UNIFIED_TURN_PLANNING_WEB_2026-09-10.json`：重启后的本地前台入口两轮 HTTP 验证，使用真实会话凭据承接“热玛吉 → 一般原理”，不包含凭据正文。

这些验证不等于全量 80 例业务评测完成，也不代表并发性能、所有医疗事实或线上环境已通过验收。外部院方信息不齐时仍会说明待核实；本次没有新增流式输出或人工消息发送能力。
