# 售前智能体能力基线

本文件把一期售前智能体的能力要求转化为可实现、可评测的运行时约束。它不授权智能体绕过医疗、隐私、知识发布、人工接管或业务系统权限。

## 已落地的核心底座

| 能力 | 当前实现 | 对客行为 |
| --- | --- | --- |
| 对话状态 | 会话保存当前目标、已确认项目/医生/偏好、待补字段、已完成步骤和话题版本 | 用户纠正或切换项目时更新目标，不重复询问已确认信息 |
| 动态路由 | `answer_route` 与 `retrieval_strategy` 分离 | 通用科普、RAG、结构化核验、GraphRAG、人工接管不再共用一条检索链路 |
| 证据与时效 | 每个引用导出为来源声明；价格、活动、排班、预约带 `verification_required` | 不把历史资料说成当前事实 |
| 工具写入保护 | 预约、活动报名、工单只生成 `confirmation_required` 动作提案 | 未确认且未接入业务适配器时，绝不宣称已执行 |
| 人机协同 | 风险触发带会话摘要、项目、已知字段和 SLA 的人工接管 | 接管后抑制 AI 自动答复，人工完结与工时原子记录 |
| 评测闭环 | v3 评测集覆盖路由、情绪、媒体、风险和多轮承接 | GraphRAG 默认误用为零是发布门禁 |

## 检索与工具路由

| 场景 | `retrieval_strategy` | 说明 |
| --- | --- | --- |
| 稳定的通用科普 | `none` + `generic_model_education` | 仅使用模型通用能力，不伪造院方事实 |
| 医生介绍、项目资料、产品公开属性、院方地址 | `rag_metadata` | 使用版本化、已审核的公开资料 |
| 价格、活动、会员、排班、预约、名额 | `structured_business_data` | 首选结构化事实源；当前没有已连接业务系统时明确提示实时核验 |
| 跨医生/项目比较、关系发现、多跳关联 | `graph_rag` | 仅此类场景允许调用 GraphRAG；索引/租户/发布绑定不通过则安全降级 |
| 外部监管或最新公开政策 | `authorized_web_search` | 当前仅输出“服务未配置”的不确定性状态；接入前不得假称已联网核验 |
| 预约、报名、工单等写操作 | `confirmation_required` | 稳定幂等动作 ID、确认、可取消窗口和受控连接器缺一不可 |

## 仍依赖外部授权的能力

- CRM、预约、会员、活动名额和支付等真实结构化数据连接器。
- 通过评审的联网搜索服务、白名单和引用存档策略。
- 用户授权的长期偏好记忆及查看、更正、删除界面。
- 图片、PDF、语音、视频的输入解析及其医疗/广告合规审核。
- 主动服务的触达授权、频控、退订和下游送达回执。

这些能力在外部依赖、权限模型和验收证据齐备前保持 `not_connected`、`provider_not_configured` 或 `manual_pending`，不能以模拟成功替代真实执行。
