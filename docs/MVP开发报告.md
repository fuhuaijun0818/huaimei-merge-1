# 时代之美·客户360 MVP开发报告

报告日期：2026-08-10  
开发状态：本地MVP功能完成；二、三级页面、6个AI员工、大模型混合运行时与开放API已补齐，并通过工程、路由、交互、API、合规与视觉验收。

## 1. 开发结果

已交付一个本地运行、零第三方npm依赖的管理端 Web SaaS MVP。系统以客户360为唯一客户详情和经营决策中枢，今日工作台、客户经营、全渠道会话、旅程自动化、AI员工、知识与合规、数据分析、集成与设置八个模块共享同一客户、事件、阶段、任务、旅程、知识和授权状态。

应用使用虚构客户与业务数据；管理端状态保存在本机浏览器 localStorage，API审计为本地服务进程内存数据。系统不连接扣子或真实医院系统；已通过OpenAI兼容接口连接已配置的模型服务。模型仅接收当次任务所需的脱敏最小上下文，不发送照片、姓名、手机号原值、完整客户360或PRD。

## 3. 关键闭环

1. 修改客户动态画像后，系统更新画像置信度、写入客户时间线并触发下一最佳动作重算提示。
2. 推进客户阶段时必须填写依据，阶段、进入时间、SLA和时间线同步变化。
3. 完成工作台任务后，任务状态和客户时间线同步更新。
4. 全渠道会话发送成功后写入客户360；命中“适用性、异常、用药、永久、一定有效、无痛”等规则时停止发送并要求人工接管。
5. 人工接管后AI停止对外发送，但仍可作为辅助模式提供知识和草稿。
6. 知识只有审批发布后才能进入生产可用状态；下架操作同时生成审计记录。
7. 旅程支持版本化、测试、发布、暂停和恢复；客户入组前展示授权、频控和互斥检查。
8. 数据分析可以下钻到客户经营列表，再进入唯一客户360。
9. 连接器测试、字段映射和同步状态均可操作，但明确标记为本地模拟。
10. CRM、企微中台、预约或合作应用可通过统一API调用指定AI员工，或由路由器按意图和售前/售中/售后阶段选择岗位。
11. 每次智能体调用经过合规前后检查；医疗适用性、异常/用药和绝对化承诺分别进入转人工或阻断。
12. A-02邀约专员和A-05复购顾问在主动触达前强制校验营销授权；调用结果通过结构化状态明确表达完成、待审批、待接管或已阻断。
13. 安全输入先由本地岗位规则生成事实草稿与已批准引用，再交给大模型生成结构化表达；模型输出必须通过JSON模式和合规后检查。
14. 确定性门禁命中时不向模型发送请求；模型超时、断网、HTTP错误或JSON无效时自动使用本地草稿降级。

## 5. 视觉与体验

- 采用温润象牙白、时代之美酒红、低饱和暖灰的品牌化色彩，不使用常见模板式紫色渐变。
- 信息密度按照医疗美容管理端场景设计，使用大留白、圆角表面、轻玻璃顶栏、低强度阴影和克制动效。
- 1440px标准桌面使用完整侧栏和三栏客户360；1024px紧凑桌面自动收起为图标侧栏并调整卡片列数。
- 支持系统“减少动态效果”设置。
- 客户照片使用本地虚构矢量头像；授权撤回时自动模糊并限制展示。

## 6. 技术实现

- 零第三方运行依赖，Node.js同时提供本地Web与AI员工API。
- 原生 ES Modules，拆分为数据、状态、UI、图标、一级页面、二三级页面、智能体运行时、API路由和OpenAPI模块。
- 使用哈希路由，无需服务端路由配置。
- 使用统一设计令牌、通用卡片/标签/表格/弹窗/反馈组件。
- 数据动作集中在 Store 层，页面不直接维护独立客户副本。
- localStorage实现本地持久化和一键重置。
- 6个AI员工共用统一请求/响应协议，支持指定调用和生命周期自动路由。
- OpenAI兼容模型适配器支持模型/端点环境变量、JSON Object模式、关闭思考输出、超时、可重试错误和令牌/延迟统计。
- 发送给模型的上下文限定为阶段、项目兴趣、已给出时段和少量需求字段；照片、姓名、手机号原值和未允许profile字段在服务端被剔除。
- API提供`X-API-Key`鉴权、常量时间密钥比较、每分钟限流、10分钟幂等重放、64KB请求体上限、Origin允许列表和结构化错误。
- OpenAPI 3.1规范、运行记录、字段脱敏和请求ID用于对接和问题追踪。

### 6.1 开放API端点

| 端点 | 用途 |
|---|---|
| `GET /api/v1/agents` | 获取6个AI员工的岗位、版本、权限和禁止动作 |
| `GET /api/v1/model/status` | 查询不含密钥的模型运行时、provider和model状态 |
| `POST /api/v1/agents/{agentId}/invoke` | 调用指定AI员工 |
| `POST /api/v1/router/invoke` | 按客户阶段和意图自动路由 |
| `POST /api/v1/compliance/check` | 独立调用合规守门员 |
| `GET /api/v1/runs` | 查询脱敏运行审计 |
| `GET /api/v1/openapi.json` | 获取机器可读OpenAPI 3.1规范 |
