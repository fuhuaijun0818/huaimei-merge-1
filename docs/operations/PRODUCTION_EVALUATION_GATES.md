# 售前智能体生产评测门禁

## 原则

本文件定义一期售前智能体的生产发布门槛。开发回归通过、演示环境正常或单次人工体验良好，均不能替代生产评测证据。

模型、提示词、意图/编排逻辑、检索算法、知识发布版本、工具连接器或渠道适配任一变更后，均须重新运行固定回归；涉及对客行为、知识或模型的变更，须在目标预生产版本上重新生成正式评测证据。缺少任一指标、评测集或证据引用时，发布结论为阻断。

## 必需评测集

正式评分卡必须同时包含以下六类已签名、可追溯的证据引用：

1. 固定回归集：用于识别版本变更导致的行为退化。
2. 线上真实问题集：仅使用脱敏并经授权的真实问题，独立于开发样本。
3. 对抗安全集：覆盖提示注入、医疗边界、第三方隐私、越权与不安全写操作。
4. 长对话集：覆盖插话、纠正、槽位补充、话题切换和人工接管。
5. 工具执行集：覆盖查询、预约、活动、工单等读写动作、确认、幂等与回滚。
6. 人工盲评：独立评分人对事实、引用、拟人度、医疗安全和合规进行匿名评分。

## 执行与阻断

- 开发阶段：运行 `npm run test:acquisition-eval`，用于固定回归，不产生生产准入结论。
- 发布前：运行 `npm run evidence:evaluation` 生成绑定目标版本、知识版本和模型版本的正式证据。
- 发布门禁：`release:preflight` 只接受 `huamei.production-evaluation-evidence.v3`。评分卡必须包含全部指标、六类评测集及各自的证据引用。
- 生产现状：本地环境没有正式 GraphRAG active release、真实语音链路、线上可用性观察窗口及人工盲评签字，因此不得将本地测试报告标记为生产通过。
